# Bank Widget — помощник для работы с банковскими операциями

Привет! Это небольшой Python-проект, который умеет:
- 🔒 **Маскировать** номера банковских карт и счетов (показывать только первые 6 и последние 4 цифры или хвост счёта).
- 📅 **Преобразовывать** дату из технического формата в человеческий `ДД.ММ.ГГГГ`.
- 🧹 **Фильтровать** список операций по статусу (`EXECUTED`, `CANCELED` и т.д.).
- 🗓️ **Сортировать** операции по дате (от новых к старым или наоборот).

Проект написан в учебных целях, но код полностью рабочий и готов к использованию.
