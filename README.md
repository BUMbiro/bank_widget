# Bank Widget — помощник для работы с банковскими операциями

Привет! Это небольшой Python-проект, который умеет:
- 🔒 **Маскировать** номера банковских карт и счетов (показывать только первые 6 и последние 4 цифры или хвост счёта).
- 📅 **Преобразовывать** дату из технического формата в человеческий `ДД.ММ.ГГГГ`.
- 🧹 **Фильтровать** список операций по статусу (`EXECUTED`, `CANCELED` и т.д.).
- 🗓️ **Сортировать** операции по дате (от новых к старым или наоборот).

Проект написан в учебных целях, но код полностью рабочий и готов к использованию.

### 💡 Простые жизненные примеры (для обычного пользователя)

**Сценарий 1: Вы смотрите историю платежей в приложении банка**

Вы открываете список операций и видите там номера карт и счетов. Вместо полного длинного номера приложение показывает маску — так безопаснее. Наши функции делают то же самое:

```python
from src.widget import mask_account_card

# Вам пришёл платёж с карты Visa Platinum 7000 79** **** 6361
# В реальных данных вы увидите только: Visa Platinum 7000 79** **** 6361
print(mask_account_card("Visa Platinum 7000792289606361"))
```

Сценарий 2: Вы хотите оставить только успешные операции

Допустим, вы копите баллы за каждую выполненную операцию. Вам нужны только те, у которых статус «EXECUTED». Функция filter_by_state отсеивает ненужное:

```python
from src.processing import filter_by_state

transactions = [
    {"id": 1, "state": "EXECUTED", "date": "2025-04-01", "amount": 500},
    {"id": 2, "state": "CANCELED", "date": "2025-04-02", "amount": 300},
    {"id": 3, "state": "EXECUTED", "date": "2025-04-03", "amount": 200}
]

successful = filter_by_state(transactions)
print(f"Успешных операций: {len(successful)}")
```

Сценарий 3: Вы хотите отсортировать траты от самых новых к самым старым

Чтобы быстро понять, куда ушли деньги за последние дни, вы сортируете список по дате. Функция sort_by_date делает это за вас:

```python
from src.processing import sort_by_date

my_expenses = [
    {"id": 1, "date": "2025-04-10T10:00:00", "shop": "Аптека"},
    {"id": 2, "date": "2025-04-12T15:30:00", "shop": "Супермаркет"},
    {"id": 3, "date": "2025-04-11T08:45:00", "shop": "Кофейня"}
]

sorted_expenses = sort_by_date(my_expenses)   # по умолчанию от новых к старым
for expense in sorted_expenses:
    print(expense["shop"], expense["date"])
# Супермаркет 2025-04-12T15:30:00
# Кофейня 2025-04-11T08:45:00
# Аптека 2025-04-10T10:00:00
```

Сценарий 4: Вы хотите показать дату операции в привычном формате (день.месяц.год)

Технический формат 2025-04-12T15:30:00 не очень удобен для чтения. Функция get_date превращает его в 12.04.2025:

```python
from src.widget import get_date

print(get_date("2025-04-12T15:30:00"))  # 12.04.2025
```
